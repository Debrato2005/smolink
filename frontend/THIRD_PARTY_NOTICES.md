# Third-party notices

The shared button adapts the Base UI recipe from [ekmas/neobrutalism-components](https://github.com/ekmas/neobrutalism-components). Its full [MIT notice](public/licenses/neobrutalism.txt) ships with the app.

Self-hosted Space Grotesk, Inter, and Space Mono fonts retain their respective [Space Grotesk](public/licenses/space-grotesk.txt), [Inter](public/licenses/inter.txt), and [Space Mono](public/licenses/space-mono.txt) SIL Open Font License notices. Font names, copyright, reserved names, and terms remain unchanged in those files.

The QR preview uses [node-qrcode](https://github.com/soldair/node-qrcode) 1.5.4 under the MIT license. Its [notice](public/licenses/qrcode.txt) ships with the app. The development-only type package `@types/qrcode` 1.5.6 keeps its [MIT notice](public/licenses/qrcode-types.txt). Both public files match the installed package licenses byte for byte. Vite copies them unchanged to `dist/licenses/`. QR generation runs only through the development fixture gateway.

GitHub and X icon paths come from [Simple Icons](https://github.com/simple-icons/simple-icons) under CC0. The [license](public/licenses/simple-icons.txt) ships with the app. No icon package is installed.

The [Source Ledger](docs/SOURCE_LEDGER.md) records adopted source, versions, alternatives, consumers, and replacement boundaries. This file preserves notices; it does not replace dependency provenance.
