# Frontend build checklist

**Owner:** Frontend implementation queue and task status

## Status contract

Allowed task states: `TODO`, `IN_PROGRESS`, `PARTIAL`, `BLOCKED_BACKEND`, `BLOCKED_CONTRACT`, `BLOCKED_DECISION`, `BLOCKED_EXTERNAL`, `DEFERRED`, and `DONE_VERIFIED`.

`DONE_VERIFIED` requires observed acceptance at the stated boundary. Source existence, screenshots, fixtures, and configured tests do not prove live integration. Exact dated receipts belong in [HANDOFF.md](HANDOFF.md). Dependencies reference stable task IDs. Commands below run from `frontend/` unless a task explicitly requires deployment or real-stack setup.
