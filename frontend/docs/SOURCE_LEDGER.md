# Frontend source ledger

**Owner:** External sources and dependency provenance

## Decision rules

Platform research checkpoint: October 5, 2026. Installed QR metadata and notices checked on October 8, 2026. Prefer repository source/tests, official documentation/standards, primary technical sources, then reputable secondary sources. This ledger separates installed dependencies from source recipes and visual references.

`SELECTED` means an installed dependency or adopted system. `SELECTED_BOUNDED_USE` means a consumed, limited recipe or primitive. `REFERENCE_ONLY` means no runtime dependency. `EVALUATED_DEFERRED` means a concrete future trigger is required. `EVALUATED_REJECTED` means the option does not fit current needs.

Exact direct versions are pinned in [package.json](../package.json). [package-lock.json](../package-lock.json) records resolved transitive versions and integrity values. Do not copy versions from dated plans. Recheck official engines, peer ranges, release notes, license, and current consumer before upgrades. Do not use `--force` or `--legacy-peer-deps` to conceal a conflict.

## Browser and security sources

[MDN safe integer guidance](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Number/MAX_SAFE_INTEGER) supports rejecting unsafe numeric IDs. [AbortSignal](https://developer.mozilla.org/en-US/docs/Web/API/AbortSignal) informs cancellation/timeout cleanup. [Clipboard writeText](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText) informs implemented success and failure feedback.

[OWASP HTML5 guidance](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html) rejects assuming localStorage is safe for session credentials. [RFC 9700](https://www.rfc-editor.org/rfc/rfc9700.html) informs the unresolved OAuth browser-binding and delivery review. These sources do not settle Smolink's missing server/session contract. It remains a documented blocker.

[Vite environment guidance](https://vite.dev/guide/env-and-mode) establishes public build-time variables and mode precedence. Production fixture refusal is a deliberate Smolink guard. Runtime libraries do not choose deployment origins or CORS policy.

[MDN scroll restoration](https://developer.mozilla.org/en-US/docs/Web/API/History/scrollRestoration) supports manual scroll restoration for the requested home reload behavior. The root route resets to the hero on reload. Initial section links keep their existing behavior.

The OncoSyn frontend document index supplied the owner separation pattern. No OncoSyn component, media, scientific contract, animation system, or session history was copied. Smolink's smaller scaffold creates only consumed responsibilities.
